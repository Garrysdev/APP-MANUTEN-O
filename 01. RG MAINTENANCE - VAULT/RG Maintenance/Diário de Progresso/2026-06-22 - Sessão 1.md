# 📝 Sessão 1 — 2026-06-22 — Migração para Firebase + CRUD Ativos/Tarefas

[[../00 - Projeto Overview|← Overview RG Maintenance]]

## Contexto

Decisão do Rui (esta sessão): **migrar de Supabase para Firebase** e **construir os CRUD MUST**
(Ativos + Tarefas/Plano de Manutenção). Resolve a incoerência antiga (plano mencionava Firebase Auth
+ Supabase DB) e a decisão pendente desde 10/06.

## Arquitetura escolhida

- **Auth:** Firebase Auth no browser (login) → ID token → **cookie de sessão httpOnly** verificado no
  servidor. Admin SDK não corre em Edge, por isso o `middleware` só verifica a **presença** do cookie;
  a verificação criptográfica é nos Server Components (Node runtime).
- **Dados:** **Admin SDK no servidor** para toda a leitura/escrita Firestore (Server Components +
  Server Actions). `firestore.rules` como defesa em profundidade (multi-tenant por `companyId`).

## Ficheiros criados

- `src/lib/firebase/client.ts` — client SDK (só auth)
- `src/lib/firebase/admin.ts` — Admin SDK, init **lazy** (build não falha sem credenciais)
- `src/lib/firebase/session.ts` — `getSessionUser()` + `getCurrentProfile()` (cookie `__session`)
- `src/lib/firebase/data.ts` — acesso a dados scoped por empresa (assets, tasks, users)
- `src/app/api/auth/session/route.ts` — POST idToken→cookie; DELETE logout (runtime nodejs)
- `src/types/models.ts` — modelos do domínio + rótulos PT
- `firestore.rules` · `firestore.indexes.json`
- `src/app/dashboard/assets/` — `page.tsx` + `AssetsClient.tsx` + `actions.ts` (CRUD completo)
- `src/app/dashboard/tasks/` — `page.tsx` + `TasksClient.tsx` + `actions.ts` (CRUD + filtros por estado)

## Ficheiros reescritos (Supabase → Firebase)

- `src/middleware.ts` — verificação leve do cookie de sessão
- `src/app/login/page.tsx` — `signInWithEmailAndPassword` + POST /api/auth/session
- `src/app/page.tsx`, `src/app/dashboard/layout.tsx`, `src/app/dashboard/page.tsx` — `getCurrentProfile`/`listTasks`
- `src/components/layout/Sidebar.tsx` — logout via `signOut` + DELETE sessão
- `package.json` — removido `@supabase/*`, adicionado `firebase` + `firebase-admin`

## Removido

- `src/lib/supabase/`, `src/types/database.ts`, pasta `supabase/` (schema.sql)

## CRUDs entregues

- **Ativos (assets):** lista + criar/editar/eliminar (modal), estado ativo/inativo
- **Tarefas/Plano (tasks):** lista + criar/editar/eliminar, filtros por estado, ligação a equipamento
  e responsável, prioridade/estado, prazo, flag "preventiva" (plano de manutenção)
